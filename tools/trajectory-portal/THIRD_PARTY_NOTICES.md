# Third-party notices

中文 | [English](THIRD_PARTY_NOTICES.en.md)

| 项目 | 许可证 | 用途 |
| --- | --- | --- |
| React / React DOM | MIT | 前端组件与渲染 |
| Ant Design / Ant Design Icons | MIT | 标准界面控件与图标 |
| Apache ECharts | Apache-2.0 | 评分图表 |
| echarts-for-react | MIT | ECharts React 绑定 |
| Vite | MIT | 前端开发与构建 |
| TypeScript | Apache-2.0 | 类型检查 |

这些项目的许可证不会改变本仓库其他代码、示例任务或上游素材各自适用的许可。
